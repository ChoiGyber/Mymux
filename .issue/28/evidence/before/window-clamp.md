# before — 첫 실행 창이 작업영역을 넘어도 그대로 뜬다

빌드: 워크트리 pure 상태(`feat/28-clamp-window-and-drop-acl` 분기 직후 = main `5cbf953`)

## 재현 방법

이 PC 모니터가 2048×1280 이라 실제 기본값 1280×800 은 넘치지 않는다. 클램프 유무를 보이기 위해
`tauri.conf.json` 의 기본 창 크기를 **일시적으로** 4000×3000 으로 두고 실행했다.
(이 임시 변경은 커밋되지 않는다. 계측이 끝나면 원래 값으로 되돌린다.)

## 결과

```text
요청한 기본 크기      4000 × 3000 (논리)
실제 창 (물리)        2566 × 1614      ← WINDOW_RECT=8,0,2566,1614
앱이 인식한 크기       2052 × 1261 (CSS px)

모니터 Bounds        2048 × 1280
모니터 WorkingArea   2048 × 1232      ← 작업표시줄 제외
```

**창이 작업영역을 폭 +518, 높이 +382 만큼 넘는다.** 좌상단(8,0)에서 시작하므로 오른쪽과 아래가
화면 밖으로 잘려 나간다.

## 왜 이런가

Tauri 는 최초 창 생성 시 작업영역으로 클램프하지 않는다. 창 상태 플러그인의 모니터 교차 검사는
**복원된 상태에만** 적용되므로(#25 에서 확인), 저장된 상태가 없는 첫 실행은 무방비다.

실사용에서 이것이 문제가 되는 조합은 1920×1080 @150% 배율이다. 논리 해상도가 1280×720 이 되어
기본 높이 800 이 화면 전체보다 커진다. 한국 노트북에서 흔한 설정이다.
